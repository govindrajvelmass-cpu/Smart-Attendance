# Database Setup - Smart Attendance

This folder contains the complete SQL initialization script for the Smart Attendance Management System.

## File
- `smart_attendance.sql`: Complete MySQL schema, tables, foreign keys, indexes, and initial BCrypt seed data.

## Execution via MySQL Workbench
1. Open MySQL Workbench and connect to your local MySQL instance.
2. Select **File > Open SQL Script...** and choose `database/smart_attendance.sql`.
3. Click the yellow lightning bolt icon (⚡) to execute.
4. Verify the `smart_attendance` database and tables in the Schemas tab.

See `backend/database/README.md` for extended details and screenshots guidance.
